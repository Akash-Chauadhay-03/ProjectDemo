Discover Java

A beginner-friendly introduction to one of the world's most widely used programming languages.

Introduction

Java is a high-level, general-purpose programming language. Developers write Java source code, which is compiled into bytecode that can run on a Java Virtual Machine (JVM).

Key features

  • Platform independent: Java bytecode can run on different systems that have a compatible JVM.
  • Object-oriented: Programs can organize data and behavior into reusable objects.
  • Strongly typed: Types help describe data and catch many mistakes while compiling.
  • Automatic memory management: The garbage collector helps reclaim memory that a program no longer needs.

Advantages

Java has a large community, extensive libraries, and tools for building many kinds of applications. Its consistent runtime and object-oriented approach make it useful for both learning programming and developing larger systems.

What is the JVM?

The Java Virtual Machine runs Java bytecode. A Java compiler turns source code into bytecode, and a JVM for a particular operating system runs that bytecode. This is the idea behind “write once, run anywhere.”

Real-life examples

Java is used in business and banking software, web server applications, data-processing systems, and many Android applications. The exact language used in a product can vary, but Java remains common in these areas.
